Badge Sync Helper

Keeps your WEB / Blu-ray / Remux tier release groups aligned with Vidhin’s Releases-Regex. By default it adds new groups only; optional strict mode also removes groups Vidhin dropped.

Step 1 — Sync from Vidhin

Click Preview to see additions (and removals if strict), then Apply sync to update the tier release-group lists in the v1 snapshot (backup/v1/oracle/nosvasedis-badges-solid.json) and regenerate formatter.json (the AIOStreams formatter name + description). Your badge JSON files are marker-based and never change from a tier sync.

Step 2 — Do this in Nuvio / AIOStreams

The v1 snapshot and formatter.json on disk are updated. Your app does not pick the new formatter up until you paste the new name + description into AIOStreams again (or refresh your synced formatter URL).

    Default: add-only (safe). Strict: mirror Vidhin per tier. Unranked tiers rebuild automatically. Tiers with no Vidhin data are never wiped in strict mode.
