# Kanso logo — ChatGPT / image-model prompt

Copy everything below the line into ChatGPT (or another image model). Prefer **square** and **transparent PNG** exports for GitHub / Nuvio.

---

## Prompt

Design a minimal logo for **Kanso**, a premium stream-badge system for the Nuvio media app.

**Brand meaning:** Japanese *kanso* — eliminate the nonessential, keep what matters. Tagline: **“No echo. Every detail once.”**

**Concept:** A single, confident mark that suggests a clean signal with no duplicate / no echo — one clear glyph, not a busy badge collage. Think quiet luxury and broadcast UI, not gaming neon.

**Visual direction:**
- One primary symbol + optional wordmark “KANSO” in a refined geometric sans (not Inter/Roboto/Arial lookalikes; something closer to a crisp tech-editorial face).
- Motif ideas (pick ONE, keep it simple): a single horizontal “signal bar” or lower-third strip with one bright node; a circle with a single clean notch (one mark); twin waves where the second is faded/cancelled (no echo); or a minimal seal/stamp with one centered mark.
- No clutter: no walls of mini-badges, no HDR/Atmos icon mashups, no play-button clichés, no Japanese calligraphy pastiche unless extremely restrained.
- Color: charcoal / near-black (#0E0E10) on soft off-white, OR inverse white mark on charcoal. One restrained accent only — cool steel blue or muted gold — used sparingly (e.g. the single “once” node).
- Flat or very subtle depth; no purple gradients, no glow haze, no glassmorphism stacks, no 3D chrome.
- Works at 32×32 favicon and at 1024×1024 hero.

**Deliverables (ask the model for each):**
1. App icon / mark only, square, transparent background.
2. Horizontal lockup: mark + “KANSO”.
3. Dark-background and light-background variants.
4. Optional monochrome version for README.

**Negative prompts / avoid:** purple AI aesthetic, neon cyberpunk, Netflix-red clones, crowded badge grids, emoji, photorealistic lenses, watermarks, busy sakura/zen clipart.

**One-line brief for the model:**  
*“Kanso — a solitary clean mark for streaming UI; no echo, every detail once.”*
