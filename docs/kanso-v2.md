# Kanso 2.2.3 — Kingsize look, Instant markers, every fact once

Kanso keeps Instant Unicode matching on structured AIOStreams fields. Visual chips use rehosted [kingsizew](https://github.com/kingsizew/badges) glyphs across four skins: Solid, Transparent (Default Colored), Mono White and Outline. Solid/Transparent/Outline chrome is Kanso-owned by category (gold picture, cyan sound, orchid locale, traffic-light resolution, blue tiers, slate source, brand streaming, unique specials). Mono stays white/black.

The formatter never prints a fact an enabled chip already shows. Language, subtitles, channels, source family/tier, CAM/TS/TC/SCR and picture tags are chips. Encode sits beside the container as `🎞️` text, not a chip. The title carries cache (`⚡`/`⏳`/`❔`), transport emoji and stars. Seeders appear on the title only for P2P or uncached streams.

## Inventory

198 canonical definitions. Compact exports 166 chips; Detailed exports 199, including six WEBRip tier variants. Best/Good/OK score chips, unranked family chips, MULTI and encoder chips stay retired. Compact hides numbered tiers and streaming origin; Detailed shows them. Hybrid, Criterion, cuts, IMAX and the rest of the specials lead the row on both presets. One source chip wins: numbered tier or generic family, never both. WEBRip remains distinct from WEB-DL.

## Language and subtitles

Forty-eight language chips and matching subtitle chips. Compact emits the preferred usable track; Detailed can emit up to four. Only languages in your AIOStreams preference list can light a chip — extra audio or subtitle languages on the file stay dark. Swedish and the rest of the inventory no longer need formatter flags. Unresolved Original/Multi/Dubbed/Unknown values do not become chips.

Chips read left to right as specials (SeaDex, IMAX, 3D, Hybrid, Criterion, cuts, B&W, remaster/proper), then streaming origin, then numbered tier or generic source, then resolution, picture, audio, channels, language and subtitles. Encode is formatter text on the release row (`📦 MKV · 🎞️ HEVC · 👥 GROUP`).
